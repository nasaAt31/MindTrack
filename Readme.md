# 🧠 MindTrack – AI Mental Wellness Tracker

MindTrack is a **web-based mental wellness tracking application** designed to help users monitor their mood, stress levels, and daily emotional well-being. It includes AI-based mood detection, journaling, and a wellness dashboard with analytics.

## 📌 Features

### 🧠 AI Mood Detection
- Automatically detects user mood from journal text
- Categorizes mood as: Happy, Calm, Sad, or Stressed

### 📓 Journal System
- Users can write daily thoughts
- Entries are saved using LocalStorage
- Displays mood + date + text history

### 📊 Analytics Dashboard
- Shows total journal entries
- Displays mood distribution
- Real-time updates from stored data

### 🌿 Wellness Section
- Daily wellness suggestions
- Stress management tips
- Mental health guidance

### 🧘 Calm Mode
- Breathing animation for relaxation
- Minimal distraction UI for focus

### 🌙 Dark Mode Support
- Eye-friendly theme toggle
- Improves usability in low light conditions
